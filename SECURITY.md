# Security

## What this repository is

This repository contains a **validation framework and an AI-agent skill** —
Markdown documents and a skill definition. It contains no production code, no
running service, no database, no payment-provider integration, and no
credentials.

## Please do not submit

Do not include any of the following in issues, pull requests, discussions, or
commits:

- secrets or API keys;
- real payment credentials;
- production webhook secrets or signing keys;
- real customer or user data;
- private account identifiers, checkout IDs, or transaction IDs;
- private or internal provider configuration;
- connection strings, private URLs, or access tokens.

Examples in this repository are fictional and synthetic by design. Keep any new
examples the same way — invent the provider, the payloads, and the identifiers.

## Reporting a security issue with this repository

If you believe there is a security problem with the contents of this repository
(for example, a file that inadvertently exposes sensitive information):

1. Prefer GitHub's private vulnerability reporting for this repository, if it is
   enabled (repository **Security** tab → **Report a vulnerability**).
2. Otherwise, contact the maintainer through their GitHub profile
   ([@Henan6](https://github.com/Henan6)) and avoid posting details in a public
   issue until the problem is resolved.

Please do not open a public issue that itself contains the sensitive content.
